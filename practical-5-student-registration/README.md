# Practical 5: Student Registration Form

A simple student registration form built with HTML5, CSS3, and JavaScript.

## Features
- Required fields for name, email, mobile, password, confirmation, course, year, gender, and terms acceptance.
- Regular-expression validation for name, email, and mobile number.
- Field-level validation messages and `aria-invalid` updates.
- Password strength indicator and confirm-password matching.
- Real-time validation using input, change, and blur events.
- Keyboard-friendly labels, fieldsets, and status messages.
- Responsive layout for desktop and mobile screens.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Note
This is a frontend validation demonstration. Successful submission does not store or send student information to a server.
